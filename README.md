## ⚠️ IMPORTANT: Data Confidentiality Notice

**This project uses 100% SYNTHETIC DATA.**

- All 1,000 clinical trials were computer-generated using Python
- No real clinical trial data was accessed or used
- No confidential IQVIA, Mendel.ai, or client information is included
- All patterns are based on publicly available patterns from ClinicalTrials.gov
- Sponsor names are completely fictional (OncoPharm Therapeutics, etc.)

This is a learning project to demonstrate Python and data analysis skills while respecting data confidentiality requirements in the pharmaceutical industry.

## 📊 Project Overview

A weekend learning project where I practiced Python data analysis by generating and analyzing synthetic clinical trial data.

### 🎯 What I'm Learning:
- **Python data generation** with realistic patterns
- **Pandas data manipulation** (groupby, aggregation, filtering)
- **Domain knowledge application** (using my clinical ops experience)
- **Clean code practices** (documentation, structure, reproducibility)

### 🔍 Questions I'm Exploring:
1. How does trial duration vary by phase?
2. What affects patient enrollment rates?
3. How does blinding type correlate with phase?
4. Do multi-site trials enroll patients faster?
5. What's the relationship between enrollment targets and actual enrollment?
